# Assets

`travel-documents.png` é uma imagem gerada com a ferramenta integrada imagegen da
OpenAI para servir de fundo. Não contém dados pessoais nem representa um documento
real. Distribuída sob a licença MIT da coleção. Nenhuma fotografia de terceiros ou
coleção pessoal de wallpapers acompanha este repositório.

Brief público: fotografia editorial horizontal de um passaporte sem marcas e
papéis de viagem sobre mesa grafite, objetos à direita, espaço escuro à esquerda
para texto. Sem texto, números, brasões ou informações de identidade embutidos.
