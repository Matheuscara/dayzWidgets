# Nord Media Card

Widget `nordMediaCard` para DankMaterialShell 1.4.6. Licença MIT, autoria Matheuscara.
Testado com Niri. Usa o MPRIS nativo do DMS, sem playerctl ou daemon adicional.

Cartão horizontal com arte à esquerda, título/artista, controles e linha de seek.
O tamanho mínimo é 320×132; recomendado 440×150. `config.transparency` controla
a opacidade do fundo (padrão 0,90). Texto, espaços e cantos seguem tokens do tema.
Botões indisponíveis ficam desativados conforme as capacidades do player.

O foco desta variante é o cartão horizontal compacto com seek e superfície
translúcida; outras opções da comunidade são igualmente válidas. Este plugin
permanece disponível no repositório enquanto o envio ao catálogo é tratado
separadamente, devido à sobreposição com players já cadastrados.

[Configuração completa](https://github.com/Matheuscara/dayzWidgets/blob/main/docs/CONFIGURATION.md).
