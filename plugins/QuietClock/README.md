# Relógio

Widget `quietClock` · DMS 1.4.6 · MIT · autoria Matheuscara.

Relógio local com data e mostrador analógico a partir de 360 px de largura.
Respeita o idioma do sistema e a opção de 12/24 horas do DMS. Texto e espaços
usam tokens do tema; a fonte se ajusta à largura disponível.

O código continua disponível nesta coleção. O cadastro no catálogo foi retirado
do primeiro lote por sobreposição com os relógios já existentes na comunidade.

[Configuração](https://github.com/Matheuscara/dayzWidgets/blob/main/docs/CONFIGURATION.md).
