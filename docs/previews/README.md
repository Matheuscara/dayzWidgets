# Prévias da coleção

Ilustrações de interface com dados fictícios, baseadas no layout, tokens Graphite e
funções dos componentes QML. Não são capturas de uma sessão pessoal nem testes
de integração do DMS. A paisagem e a capa do álbum são desenhos originais para
demonstração; nenhum comando, cofre, localização ou imagem pessoal é usado.

Gerar novamente, com Chromium/Chrome e ImageMagick instalados:

```bash
python3 scripts/render-previews.py
```

O render ocorre em arquivos temporários, sem alterar a configuração do desktop.
Os PNGs resultantes são versionados e exibidos na grade do README.
